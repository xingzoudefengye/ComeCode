# 会话侧栏与滚动条外观

新建 TUI 默认隐藏右侧介绍/状态侧栏，不预留侧栏宽度。保留现有快捷键切换：宽终端停靠，窄终端覆盖，状态仍由 useSidebarController 单一管理。

会话滚动轨道复用 DARK_TUI_THEME.background（#141414），在浅色和深色主题下保持显式深色。仅修改 trackOptions.backgroundColor，不改变箭头、宽度与滚动链路。

滑块改由 patches/@mbears__opentui-core@0.2.15.patch 用整格背景填充绘制：OpenTUI 原生按格写 █/▀/▄ 字形，字形高度受终端字体行高限制，行间会露出轨道底色，看起来像一串小方块（半格滑块更像一小段短横）。整格背景由终端铺满整个单元格，观感与原生滚动条一致；滑块边界按整格取整，鼠标拖拽与滚轮逻辑不变。

顶部品牌及底部状态和上下文缓存信息不变。

验收：宽窄终端初始化均隐藏侧栏；手动切换仍可打开和关闭；两种主题的原生 slider 均收到显式深色背景。构建不会自动更新已安装的 comecode。

用户消息的 `>` 提示符与列表标记左对齐，不额外保留用户消息专属的左侧 padding；提示符后的内容和多段续行缩进保持不变。
