# M4.1–M4.4 本地模型管理页

## 范围

- 仅实现三种执行协议的配置管理：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。不新增 Gemini 原生执行；旧 Gemini 配置保持可识别且不允许执行。
- 网页提供供应商/模型增删改、默认选择、协议/地址/凭据继承、显示名/窗口/输出上限/工具及视觉能力。会话、记忆、日志按实际需要扩展；不建设多实例 Hub。
- 使用 `comecode admin` 独立打开配置管理（不启动模型），端口用 `--port`（`--web-port` 为兼容别名）；TUI 不再同进程内嵌管理页，`--no-web` 已移除。网页对话工作台是另一条入口，由 `comecode --web` 提供（见下节），本文档的管理页只在显式执行 `admin` 时监听，不新增未请求的端口。无头/协议/help 不启动后台。

## 网页对话工作台 `--web`（2026-10-09）

- `comecode --web` 启动网页对话工作台：CLI 自身以 `app-server --stdio` 子进程承担 Agent，`@zcode/server` 提供 HTTP/WebSocket，`@zcode/web` 提供静态产物；管理页仍只由 `comecode admin` 提供。三者与 CLI、桌面读写同一份 `~/.comecode` 配置与会话存储，不新建第二套会话、记忆或状态。
- 参数：`--port`（`--web-port` 兼容别名；0 或未指定时自动挑空闲端口）、`--host`（默认 `127.0.0.1`）、`--open`/`--no-browser`、`--token`/`--no-token`、`--workspace`。`--web` 不与位置参数、`--prompt`、`--target`、`--import` 同时使用，冲突时直接报错退出。
- 鉴权：监听本机地址默认不带令牌；`--host` 指向非本机地址时默认生成随机令牌并写进打印的地址，`--no-token` 显式关闭。启动子进程时显式写入 `ZCODE_SERVER_AUTH_TOKEN`（关闭时为空串），避免继承的旧值意外开启后端鉴权。
- 生命周期：网页服务是子进程，退出时先 SIGTERM、1.5 秒内未退出再 SIGKILL；Ctrl+C/SIGTERM 转发为子进程退出。stdout/stderr 直接转发，不缓冲日志。
- 资源解析：优先安装包布局 `<root>/{web,server,agent}`，其次 monorepo `packages/{web/dist,server/dist}` 与 CLI `dist/zcode.cjs`；缺少任一项时打印构建指引并返回失败，不启动半成品服务。
- 验收：`apps/zcode-cli/test/web-command.test.mjs` 覆盖 TUI 判定、参数与帮助文案、打包/回落布局解析、缺资源失败；发行打包脚本对解包产物真实启动一次 `--web` 并请求 `/api/server-info` 冒烟。

## 所有者与边界

网页 → CLI 本地 HTTP 边界 → adapters 配置编辑仓库 → config.json → 现有统一解析 / materialize → Registry。

- 桌面设置页与 Web/内置管理控制台共用此用户级配置事实源；`v2/provider_config.json` 仅由统一配置物化为兼容 Registry 投影，不能作为另一套可写配置或删除状态来源。
- 用户配置为可编辑来源，项目覆盖、环境/CLI 覆盖仅只读展示，不将合并后的环境密钥写回用户文件。
- adapters 提供读取、脱敏、乐观版本校验与备份后保存的公共接口。CLI 不另写一份解析器。
- 原 JSONC/TOML 保存到 JSON 前需用户明确确认迁移，原文件备份并保留；不静默丢失原始注释。含未知字段/非法结构的文件拒绝编辑写入。
- 版本摘要覆盖同目录 JSON/JSONC/TOML 三个文件；同一服务器写入串行，外部修改/第二页面旧版本保存返回 409，不覆盖。原始文件备份含密钥、权限 0600；写临时文件后 rename 生成 JSON。用户原密钥未修改时按供应商/模型来源保留，改名或迁移不要求重填；删除密钥必须显式操作。

## 配置易用性优先（2026-10-04）

- 用户级模型与 Key 配置一次，所有项目直接复用；切换工作区不要求重新填写凭据或逐项目信任授权。
- 不新增 Provider/MCP 的逐项目审批命令，不以本轮配置改造改变既有权限体验。
- 配置隔离已实现：项目临时覆盖通过独立运行时快照解析，不写回全局来源，不污染其他项目。

## M6 桌面共享配置与会话底层闭环（2026-10-04）

- Electron Main → window-scoped Host → CLI `app-server --stdio` 保持不变；不创建第二套 Agent、消息库或记忆。桌面应用身份为 ComeCode，默认数据根与 CLI 一致为 `~/.comecode`。
- Host 的模型就绪视图启动前使用 adapters 的统一配置解析器读取全局 JSON/JSONC/TOML 及兼容 Provider 文件，不要求登录、重复 Key 配置或逐项目授权。Host 使用独立临时派生快照，不覆盖用户配置；CLI 子进程继续按实际 workspace 解析项目覆盖。
- 配置来源唯一为统一配置文件；Host 快照仅供既有 Registry/模型选择展示和就绪判断。当前阶段不改造完整桌面模型编辑界面；旧编辑界面不能被视为统一配置编辑入口，CLI admin 仍是已验收的写入入口。
- `COMECODE_DATA_BASE_DIR` 优先于兼容的 `ZCODE_DATA_BASE_DIR`；Host 显式数据根传入子进程，配置和会话存储不得因 Electron 的 home/userData 或子进程 cwd 而分叉。显式 storage/sessionDbPath 继续优先。
- 默认不刷新厂商 Provider CDN，不因无厂商账号自动打开登录页；远程、CUA 和手动登录能力保留，不为共享闭环删除已实现功能。
- 会话所有者仍是 CLI Runtime/SessionStore；两端通过现有 session/list、session/resume 与 prompt 路径恢复相同 session ID、消息及模型选择。桌面任务索引仅作可重建投影，不导入旧 `.zcode` 数据，不自动重放崩溃时未完成的工具。
- 可写 Runtime 在创建/冷恢复时通过 adapters 的跨进程会话 lease 获取独占所有权（数据库路径 + session ID）；同一进程重复创建同一会话亦拒绝。持有者存活或身份无法确认时失败关闭，不按超时偷取；正常关闭释放，进程死亡后按 PID 探测回收。恢复失败释放 lease；只读列表/历史读取不获取 lease。该阶段不自动转交、不自动重放工具，进程外修改存储不属于 lease 契约。
- 验收使用临时数据根、虚构 Key、本地 HTTP mock 及真实 stdio 子进程，覆盖 CLI 创建→Host 恢复继续→CLI 恢复继续、跨项目配置复用及隔离、配置错误、兼容来源与无厂商请求。桌面 UI 实机、完整工具/权限/压缩组合和跨进程 writer 仲裁未经测试不得标记为完成。

```text
全局 config → adapters 统一解析 → Host 临时 Registry 视图（启动门禁）
                         └── CLI app-server（workspace 覆盖）→ 同一 SQLite/Runtime
CLI 恢复 ← session ID / 存储 ← Host session/resume ← Renderer
```

## 共享会话管理页（2026-10-04）

- 复用现有 CLI admin，左侧导航切换模型与会话；不新增 Web 聊天、Agent、配置源或数据库。模型保存与可选测试保持独立。
- 会话事实由现有 SQLite SessionStore 持有。HTTP 通过公共存储契约查询；列表在 SQLite 内按标题/目录搜索、分页，默认隐藏归档，归档筛选只展示归档记录。排序为更新时间及 ID 降序，每页最多 100 条。不存在数据库时返回空列表，不创建目录或数据库；已有数据库使用只读连接，不执行迁移。
- 历史通过 bootstrap transcript 投影，只查询一页消息，不加载整个会话；最多 50 条消息，返回文本总量有界，不暴露原始模型专用消息和工具输入/输出。读取不创建 Runtime、不申请 writer lease、不发模型请求。
- 管理页仅显示有可见正文的历史消息；工具/思考专用记录及空白正文不输出空的“助手”标题，不修改原始存储或其他客户端的结构化投影。分页游标仍按原始消息页推进，空正文页保留下一页入口。
- 详情提供独立的“复制会话 ID”；每条可见正文提供“复制”，仅复制该条正文；详情提供“复制已加载对话”，按展示顺序带用户/助手标签复制已加载内容，不包含会话 ID、恢复命令或未加载历史。截断内容明确保留截断提示，不宣称全文。剪贴板拒绝时提示失败，不显示成功；旧浏览器使用本地复制降级，不向服务器发送内容。
- 重命名限定 30 个 Unicode 字符；重命名与归档/取消归档先获取现有跨进程 session writer lease，再读取及校验更新时间，写入后 finally 释放。活 owner 占用返回 409，旧详情写入返回 409，未知会话返回 404；不提供永久删除，不借用 V4 deleteSession。
- 安全边界沿用 token、Host/Origin、CSP、JSON 及请求大小限制；不开放 frame、任意 origin 或 UI 直连 Repo。
- 浏览器和桌面控制台展示带 `--cwd` 的 `comecode --resume <session-id>` 恢复命令，保留会话工作目录。桌面设置页通过平台命令打开同一受控管理窗口；本版不声明控制台直接恢复桌面的能力，不以 HTTP 启动第二个 Agent。
- 验收以临时 SQLite、虚构配置和本地 HTTP 为准，覆盖搜索/分页、归档往返、标题变更、历史隐藏与上界、租约占用、过期写入、鉴权与非法参数；不读取真实配置、不发付费请求。

## HTTP 安全与生命周期

- 只监听 127.0.0.1，随机 32 字节 token。分享 URL 使用 fragment，不写 token 到 URL query/服务器日志；浏览器读取 token 后清理地址栏并仅存 sessionStorage。
- `/api/*` 全部校验 Bearer token（常量时间比较）；检查 Host 和 Origin，拒绝非同源 Origin/跨站请求/非 JSON 写入；限制请求体 256 KiB。
- 页面 CSP 禁止外部资源与 inline 脚本（nonce 或独立脚本）、不允许 framing，API/page 均 no-store、nosniff、no-referrer。
- 密钥不返回网页，表单只显示“已配置”；新增 Key 使用 password 输入，保存后清空；diagnostics 和异常不输出凭据/远端响应正文。
- `测试连接` 只由用户点击触发一次最小请求，不弹二次确认；测试可能消耗额度，超时 15 秒，返回成功/HTTP 状态，不回显正文或密钥。新增/编辑模型及供应商只要本地结构合法即可保存；测试可选，未测试、失败或修改已测试表单均不锁保存。保存不会隐式发起连接测试。
- `admin` 进程等待 SIGINT/SIGTERM 后关闭监听。TUI return/failure 的 finally 关闭后台，连接不阻止退出；端口占用明确报错，不隐藏失败。

## 简化默认页面（2026-10-01）

- 页面默认直接展示扁平模型列表，不要求用户先理解 Provider；添加模型时只展示接口地址、API Key、协议（默认 Chat Completions 兼容）和模型名，能力与窗口放入“更多设置”。

## 模型启用/停用（2026-10-01）

- 模型卡片提供可用键盘操作的启用/停用开关，旧配置及新模型未声明 `enabled` 时默认启用；停用卡片仍保留，可继续编辑、删除和重新启用。
- 模型级 `enabled: false` 由统一配置所有，网页开关变化后自动保存；不提供外层“保存配置”操作，不中断运行中的会话。
- 停用不删除模型、凭据或显式能力（尤其是 contextWindow）；后台重新加载仍展示停用项。JSON/JSONC 支持此字段；原 TOML 模型字符串保持默认启用，网页保存按既有规则确认迁移为 JSON。
- 默认模型下拉框排除停用项；停用默认模型时优先选择同一供应商的可执行模型，再选择其他供应商的可执行模型，全部停用时清空默认。
