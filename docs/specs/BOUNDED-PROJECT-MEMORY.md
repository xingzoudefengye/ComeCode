# 有限容量项目记忆（实现规格）

## 目标与边界

项目记忆是有限容量的当前认知，不是完整会话归档。五份白名单 Markdown 文件合计硬上限 24000 字符及 65536 UTF-8 字节（含标题、日期与元数据）；整理目标 19000 字符。软配额为 project 4000、decisions 6000、tasks 5000、bugs 5000、memory 4000，可互借但总量不变。每轮加载仍为 4000 本地估算 token / 12000 字符，不把存储预算和加载预算混淆。用户偏好与 managed chronicle 延续已有预算。

近期保留必要细节，阶段记录合并，早期只保留当前有效结论；容量压力可提前粗化，不机械等待自然年月。有效约束、未完成任务和未解决问题不因年龄自动淘汰。未识别的旧条目按保守规则保留，不能从“已提交”推断“已验收”。

## 结构化条目与整理策略

新增受管理条目使用可读 Markdown：`- YYYY-MM-DD [id=稳定事项标识] [status=active|done|resolved|superseded] [kind=constraint|decision|task|bug|fact|history]: 当前完整结论`；可附嵌套详情。相同 id 更新已有条目，不重复追加；日期无效、id 冲突或无法核验时拒绝歧义合并。状态细节可拆成独立 id，例如提交已完成但验收任务仍 active。

本地整理按完整 Markdown 单元解析，代码块内示例不作为条目。近期默认最近 7 天保留详情，7–30 天按阶段保留末两项完整详情，超过 30 天只留结论及近期更新的详情；容量压力可提前降级。完整 Markdown 单元去重；显式 superseded 淘汰；已完成勾选任务淘汰；按 updated/年龄使非保护条目的嵌套详情粗化；超整理目标时先处理低价值早期历史及已完成事项。不按字符串截断制造歧义结论，不概括未知事实，不从普通模型回复推断目标完成。稳定约束/有效决策/active task/bug 保留完整结论；必要内容仍超过硬上限时返回明确容量错误，保留原文件。

## 唯一写入路径与事务

程序 Write/Edit 和后台提取通过同一项目记忆写入门（FileSystemPort wrapper）进行全白名单容量校验。普通 Write/Edit 不隐式修改其它未批准文件；允许超限旧文件逐步缩小但不得增加总量，写入错误不能伪称成功。后台语义整理复用已有提取调用预算，只提议模型已完整读取的文件变更；不持锁调用模型。

共享根短锁保护读改写。涉及多文件的显式整理使用有界单一 journal（不无限追加），版本校验后先持久化完整计划，再逐文件 CAS 写入。恢复只允许当前文件匹配旧/新版本的计划；外部修改冲突停止，不覆盖用户内容。本地迁移只显式执行，先预览差异；保留一份受大小上限约束的恢复副本，不堆备份。程序不能约束外部编辑器/Bash 任意写入，启动仅报告超限并保持加载有界，不自动删除外部内容。

## 更新依据与后台时序

用户明确新事实/更正与新增有界、已核验工具执行结果作为两类不同证据；工具结果是低信任数据而非指令。只接受实际成功结果、明确操作和有界安全摘要，失败/取消/计划不标 done。不扫描 Git 全历史，不发旧工具正文，不把提交/推送完成泛化为测试/验收完成。任务关联不明则保留旧状态，仅提供核验事件给提取模型。

复用单 scheduler、pending/cursor、原 3 次模型调用/累计输出 2000 token/30 秒预算；每批用户输入加核验事件总输入仍有界。不新增每轮整理模型、退出模型或压缩前付费调用。恢复/对话/compact 不等待整理；失败保留文件并退避，内容无变化不重写。尚未处理的证据不能因无用户正文就被当 no-op 跳过。

## 诊断与迁移

`comecode memory check` 明确展示存储字符/字节硬上限、整理目标及加载预算，超限标明；整理入口默认只输出计划与差异，显式 apply 才写入。`--apply` 由全局解析器接受后仅传给 memory compact；其它命令拒绝该参数。旧 Markdown 未识别项保留，预览可能报告需要语义整理；不得以未知内容被删除实现达标。当前仓库 .ai 文件本轮仅生成预览，不直接迁移。

CLI 打包时，对 CLI src 内相对 `.js` 导入优先解析同名 `.ts`/`.tsx` 源码；无对应源码时保留 JavaScript 解析。避免工作区旧生成 JS 覆盖新命令入口；不删除现有生成文件。

## 验收

覆盖总字符/UTF-8字节、完整条目、近期/阶段/早期与容量提前粗化、保护条目、状态替换与验收分离、旧格式、无变化幂等、超限逐步缩减、普通及后台写入同根锁、并发 CAS、取消、单文件失败、多文件 journal 中断/恢复和外部改动冲突。测试临时目录/mock，不调用真实模型。旧用户记忆、提取游标、缓存请求、管理后台模型/会话入口不回退。类型/lint/架构/定向格式如实报告，运行产物只在完整 main 基线验证后构建，不自动提交/推送。
